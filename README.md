# Azure Python AI

A small Python application that connects to
Microsoft Azure AI Foundry and sends user questions
to a deployed Phi-4-mini-instruct model.

## What I learned

- Connecting Python to Azure AI Foundry
- Using the OpenAI Python SDK
- Working with environment variables
- Using .env and .gitignore for secrets
- Structuring Python code with functions
- Handling an AI API response

## Tech

- Python
- Azure AI Foundry
- Phi-4-mini-instruct
- OpenAI Python SDK
- python-dotenv
